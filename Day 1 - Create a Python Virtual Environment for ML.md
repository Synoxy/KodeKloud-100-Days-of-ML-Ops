🚨 **Problem Statement:**
Create a Python Virtual Environment and run requirements.txt in the Virtual Environment.

🛠️ **Solution:** Run below Commands in the Visual Studio Terminal
**Commands**: 
- python -m venv ml-ops # Create the virtual env
-  source ml-ops/bin/activate |  source ml-ops/Scripts/activate # Activate the virtual env
- pip install requirements.txt  # Install the requirements file
